# E-Commerce Sales Analytics Dashboard | Power BI

## About the Project

I created this project to explore how data analytics can help businesses understand their sales performance, customer behaviour, product returns, and customer value.

While working on this project, I used Power BI to transform raw e-commerce data into interactive dashboards. My goal was not just to create charts, but to understand what the data can tell us about business performance and how it can support better decision-making.

This project is part of my learning journey as a Master's student in Data Science.

## Project Objectives

The main objectives of this project are to:

- Analyse overall sales, revenue, profit, and profit margin.
- Understand customer purchasing behaviour and repeat purchases.
- Analyse product returns and identify common return reasons.
- Segment customers based on their purchasing behaviour using RFM analysis.
- Build interactive dashboards that make business insights easier to understand.

## Tools Used

- **Microsoft Power BI** – Data modelling, DAX calculations, and dashboard development.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – Creating measures and business calculations.
- **GitHub** – Sharing the project, report screenshots, and documentation.

## Dashboards Included

### 1. Sales Performance Overview
This dashboard provides an overview of business performance through key metrics such as revenue, cost, profit, profit margin, orders, customers, and units sold. It also allows users to explore sales trends across different categories, countries, and time periods.

### 2. Customer Analysis
This page focuses on customer purchasing behaviour. It includes repeat customer analysis, customer revenue, average order value, and comparisons across customer types and countries.

### 3. Product Returns Analysis
This dashboard explores returned products, return rates, monthly return trends, and reasons for returns. It helps identify areas that may need further investigation from an operational perspective.

### 4. RFM Customer Segmentation
I used Recency, Frequency, and Monetary (RFM) analysis to group customers according to how recently they purchased, how frequently they purchased, and how much they spent.

The resulting segments include Champions, Loyal Customers, Potential Loyalists, At Risk, Hibernating, and Others. This type of analysis can help businesses understand customer value and plan more targeted retention strategies.
